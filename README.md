# 좌표평면 오목 (중학교 1학년 · 좌표평면)

2인 1조, 조 vs 조(4명)로 하는 좌표평면 오목입니다. 조 안에서 한 명은 **좌표만 말하고**, 한 명은 **점만 찍습니다.**

## 주소
- 학생용: `index.html` (교사용 화면의 [학생용 주소 복사]를 쓰면 수업 코드가 자동 입력)
- 교사용: `teacher.html`
- 시연: `index.html?demo=1` (선생님 vs 컴퓨터, 코치 말풍선)

## 규칙
1. 4명이 흑돌 조·백돌 조로 나뉘고, 조마다 말하는 사람·찍는 사람을 정합니다.
2. 말하는 사람은 놓고 싶은 자리의 좌표를 패드에서 몰래 고른 뒤 짝에게 말로만 알려 줍니다.
3. 찍는 사람이 말한 좌표와 다른 곳에 찍으면 ✗ — 차례를 잃습니다(교사 설정으로 '다시 찍기'로 바꿀 수 있음).
4. 먼저 4개(또는 5개)를 한 줄로 놓는 조가 이깁니다.
5. **번갈아 부르기(기본)**: 우리 조 차례가 끝날 때마다 말하는 사람과 찍는 사람이 바뀝니다. 끄면 판마다 바뀝니다.
6. 찍는 사람 화면에도 짝이 고른 좌표가 뜹니다(교사 설정에서 끌 수 있음).
7. 끝나면 한 줄로 놓인 점들의 좌표를 보여 주고 규칙(가로줄은 y좌표가 같다 등)을 생각해 보게 합니다.

## 🆕 교사 화면 새 구성 (v11) — 숫자 야구 대전·주사위 게임에서 가져온 것
- **탭 구성** (홈은 숫자 야구 대전과 같은 순서): 위쪽 줄에는 늘 수업 코드, **✋ 멈추기**, 📽 수업 슬라이드, 📐 굵은 선이 있어요.
  - **🏠 수업 진행**(수업 중에 보는 것): 수업 코드·주소 복사·📺 크게 보기 / 전체 멈춤·모두 처음 화면으로·학생이 쓸 수 있는 방식(2:2·1:1·컴퓨터·혼자) / ✋ 손든 학생 알림 / 🎮 게임 방 현황 / 접속한 학생 / 학생별 점수·전적
  - **🙋 도울 학생** · **📝 좌표 퀴즈** · **💰 포인트**(점수 값 설정·조정·기록) · **📒 기록**(학생별 자세한 기록·경기 기록·CSV) · **⚙ 게임 설정**(몇 목·단계·운 요소·규칙) · **💾 백업·초기화**
- **📺 크게 보기**: 수업 코드와 함께 **QR 코드**가 크게 떠요. 패드 카메라로 찍으면 수업 코드가 들어간 주소가 열려요.
- **🎮 게임 방 현황**: 방마다 방 코드·방식·단계·몇 목, 흑돌 조·백돌 조 학생(말하기/찍기, 💰 포인트), 대기실 앉은 수, 놓은 돌 수, 누구 차례, 끝난 판 결과, 이 방에서 한 판 수(흑:백)가 바로 바뀌어요. 방에 들어가지 않은 학생도 따로 보여요. (방장 패드가 알려 줘요. 교사 화면을 새로고침해도 다시 받아요)
- **학생별 점수 · 전적**: 포인트 순위와 대전 승·패·무, 컴퓨터전, 찍기 정확도를 한 표에서.
- **📽 수업 슬라이드** (주사위 게임과 같은 PPT 모양, 16:9 전체 화면): 표지 → 학습목표 → 수업에 들어와요(QR) → 사분면 → **x축 위의 점은?(의견 받기)** → 점의 좌표 읽기 → 좌표에 맞춰 점 찍기 → 좌표평면 오목 방법.
  - ← → 키(프레젠터 리모컨)로 넘겨요. 그림이 있는 장은 → 를 누를 때마다 수선·화살표·답이 하나씩 나타나요.
  - **❓ 의견 받기 장**: [학생에게 질문 보내기] → 학생 패드에 고르기 + 까닭 쓰기 창이 떠요. 고른 답 막대와 까닭 카드가 슬라이드에 모이고(이름 가리기 기본), [✔ 정답 공개]를 누르면 학생 패드에도 정답과 설명이 떠요. 다른 장으로 넘어가면 질문이 자동으로 닫혀요.
  - 아래 막대: ✋ 멈추기 / ▶ 활성화, ✏ 글 고치기(이 브라우저에 저장), ↺ 이 장 처음대로, ⛶ 전체 화면. 기본 내용과 그림은 `slides.js`.

## 🧩 다른 웹앱에서 가져온 것 (v9)
- **✋ 손들기** (한 걸음 수학): 학생 화면 위쪽 [✋ 도와주세요]를 누르면 교사 화면 '도울 학생' 탭 맨 위에 손든 순서대로 떠요. [✓ 확인했어요]를 누르면 학생 화면 손이 내려가요.
- **📖 낱말 사전** (한 걸음 수학): 게임 방법·퀴즈 풀이·도움말의 파란 밑줄 낱말(좌표평면, 좌표축, x축, y축, 원점, 순서쌍, 좌표, x좌표, y좌표, 사분면)을 누르면 교과서 뜻이 떠요.
- **🎉 색종이 축하**: 이겼을 때, 퀴즈·충전 문제·규칙 고르기를 맞혔을 때.

## 📚 교수학적 보완 (v8)
- **단계**(교사 화면 설정): 하 = 제1사분면과 축 위(좌표 0~5)만, 중 = 네 사분면, 상 = 눈금 숫자 없이. 하 단계에서는 사분면 주사위를 쓰지 않아요.
- **규칙 고르기**: 판이 끝나면 한 줄로 놓인 점들의 좌표 규칙(x좌표가 모두 같다 등)을 직접 골라요. 선수가 맞히면 +2점(한 번만). 설정에서 끌 수 있어요.

## 🤺 1:1 대전 (v7)
- 첫 화면에서 [👥 2:2 방 만들기] 또는 [🤺 1:1 방 만들기]를 골라요.
- 1:1은 두 사람이 번갈아 **판에서 점을 누르고 그 점의 좌표를 골라요**(점 → 좌표). 좌표가 맞아야 돌이 놓이고, 틀리면 차례를 잃어요(실수 유형은 도울 학생 탭에 '읽은' 실수로 기록). 2:2는 좌표 → 점, 1:1은 점 → 좌표를 연습해요. 몇 목·사분면 주사위·포인트·판돈은 2:2와 같아요.
- 교사 화면 [설정 · 멈춤] → 방 만들기에서 2:2, 1:1을 각각 끄면 그 방식은 잠겨서 새 방을 못 만들어요(이미 하던 판은 계속).

## 💰 포인트 (v6)
- 학생 이름은 `번호 이름` 꼴로 정리돼요("7김민지", "07번 김 민지" → "7 김민지"). 번호 없이 이름만 쓰면 들어갈 수 없어요. 포인트는 이 이름으로 이어집니다.
- 기본: 처음 100점, 맞게 찍기 +1, 대전(2:2·1:1) 이긴 사람 +5(무승부 +2), 컴퓨터 이기기 +3, 좌표 퀴즈 정답 +3(정답 공개할 때 지급). 혼자 연습은 포인트 없음.
- **판돈**(기본 0 = 안 걺): 진 조가 이긴 조에게 줘요. 걸리는 점수는 [판돈]과 네 명 중 가장 적게 가진 사람의 점수 중 작은 쪽(제로섬).
- **연속 제한**: 같은 사람들끼리 연속 3판을 넘으면 그 판은 승리 점수·판돈 없음(맞게 찍기 점수는 그대로).
- **충전 문제**: 포인트가 10점보다 적으면 첫 화면에 [🪙 좌표 문제 풀고 포인트 받기]가 떠요. 문제는 교사 화면이 만들고 채점(맞히면 +2, 4초 간격).
- 교사 화면 **💰 포인트** 탭: 점수 값 바꾸기, 학생별 ±1·±5 조정, 오늘 변화, 최근 기록, CSV, 📺 순위 크게 보기, 모두 처음 점수로.
- 장부는 교사 화면이 원본(이 컴퓨터 브라우저에 저장, 백업 파일에도 들어감). 학생 화면은 보여 주기만 해요.

## 🙋 도울 학생 (v6)
- 찍는 사람이 말한 좌표와 다르게 찍으면 실수 유형을 가려서(x·y 바꿈, x 부호 반대, y 부호 반대, 두 부호 반대, 한 칸 어긋남, 다른 곳) 그 학생 화면에 💡 도움말을 보여 줘요.
- 오늘 3번 이상 틀린 학생은 교사 화면 **🙋 도울 학생** 탭에 최근 실수와 가장 많은 유형이 떠요. 도와준 뒤 [✓ 도왔어요]. 반 전체 실수 유형 막대도 있어요.

## 📐 굵은 선 (v6)
교사 화면 위쪽 [📐 굵은 선]을 누르면 학생 화면 좌표평면·퀴즈 그림이 함께 굵어져요(TV·프로젝터용). 다시 누르면 기본 선.

## 운 요소: 사분면 주사위 (교사 설정에서 켜기)
- 차례마다 말하는 사람이 주사위를 굴립니다. 1~4: 그 사분면, 5: x축·y축 위, 6: 아무 데나.
- 나온 구역 밖의 좌표는 고를 수 없고(앱이 막음), 판에 그 구역이 옅게 칠해집니다. 구역이 꽉 차 있으면 아무 데나.

## 수업 코드
- 교사용 페이지의 수업 코드는 이 컴퓨터의 브라우저에 저장되어 새로고침하거나 창을 닫았다 열어도 바뀌지 않습니다.
- 같은 브라우저에서 교사용 창을 하나 더 열면 예전 창은 자동으로 멈춥니다.

## 교사 기능
- 수업 코드, 학생용 주소 복사, 📺 크게 보기(QR), 📽 수업 슬라이드, 🎮 게임 방 현황
- 몇 목(4/5), 틀렸을 때 벌칙, 2명 vs 컴퓨터·혼자 연습 허용
- ✋ 전체 멈춤, 🏠 모두 처음 화면으로
- 좌표 퀴즈(점의 좌표 읽기 / 좌표로 점 찾기 / 어느 사분면?) — 답 분포, 정답 공개, 📺 화면 띄우기
- 기록: 학생별 대전·승패·찍기 정확도, 경기 기록, CSV
- 백업 저장/불러오기(포인트·실수 기록 포함), 초기화(포인트·실수 기록도 골라서)

## 인원이 4명으로 안 나뉠 때
- 2명 남으면: [우리 조(2명) vs 컴퓨터]
- 1명 남으면: [혼자 연습하기] (좌표만 골라서 컴퓨터와 대결)

## 연결 (Firebase Realtime Database)
기기끼리 직접 연결하지 않고 모두 Firebase(프로젝트 `daicheong-math`)를 거칩니다. 학교 와이파이가 기기 간 연결을 막아도 됩니다.
- `fbnet.js`: Firebase 위에서 '연결'을 흉내 내는 작은 도구 (교사 화면·방장이 hub를 차지, 학생은 up으로 보내고 dm·down·view로 받음)
- 데이터 위치: `omok/{수업 코드}/…` (교사 연결), `omok/{수업 코드}/rooms/{방 코드}/…` (학생 대전 방)
- 설정값: `firebase-config.js` / 데이터베이스 규칙에 `omok`이 들어 있어야 합니다.
- 교사 화면을 닫거나 새로고침해도 학생끼리 하던 경기는 계속되고, 교사 화면이 다시 열리면 학생 연결이 자동으로 이어집니다.
